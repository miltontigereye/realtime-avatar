# RealTime Avatar research context

Start with [research-context/INDEX.txt](research-context/INDEX.txt), then read the project plan, results, and selected algorithm sources it lists.

This repository currently contains a curated research reading snapshot: core attention, caching, sampling, distillation, and streaming implementations with upstream licenses, revisions, and file hashes. It excludes model weights, datasets, media, environments, and generated build files. These excerpts retain external dependencies and are not complete runnable upstream projects.

For Codex or Claude research, select `research-context/project/` and the relevant method under `research-context/sources/`. Read the deployed AURA sources when proposing integration changes. Treat upstream README performance claims separately from the measured results in the project documents.

GitHub is the shared handoff point: commit research proposals and prototype changes on separate branches for review before testing on local, rtx1, or rtx2. Refresh imported project files after GitHub changes. The deployed runtime and the full local working tree are not mirrored by this reading snapshot.
