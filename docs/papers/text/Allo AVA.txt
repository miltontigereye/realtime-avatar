F     Computational Resources and
      Optimization
F.1   Hardware Specifications
The Allo-AVA dataset was processed using the fol-
lowing hardware setup:

    • 8 NVIDIA A40 GPUs (48GB VRAM each)

    • 2 AMD EPYC 7742 64-Core Processors

    • 1 TB RAM

    • 200 TB NVMe SSD storage

F.2   Optimization Techniques
To efficiently process the large volume of data, we
employed several optimization techniques:

    • Parallel processing using Python’s multipro-
      cessing library to utilize all available CPU
      cores.

    • GPU acceleration for keypoint extraction and
      video processing tasks using CUDA-enabled
      libraries.

    • Efficient data loading and preprocessing us-
      ing PyTorch’s DataLoader with custom collate
      functions.

    • Caching of intermediate results to avoid re-
      dundant computations.

  These optimizations allowed us to process the
entire dataset in approximately 3,000 GPU hours.
